# Prompt para geração assistida das aulas

Use o livro e o JSON de exercícios como fontes. Para cada capítulo:
1. identifique objetivos observáveis;
2. divida em aulas de 8–20 minutos;
3. crie etapas curtas;
4. adicione posições FEN legalmente válidas;
5. defina expected actions e feedback específico;
6. associe exercícios existentes;
7. cite páginas fonte;
8. evite copiar longos trechos literais do livro; faça redação didática própria;
9. valide toda linha com o motor de regras;
10. produza JSON conforme `course/lesson.schema.json`.

Antes de publicar, rode validator, teste de navegação de etapas e revisão humana.
