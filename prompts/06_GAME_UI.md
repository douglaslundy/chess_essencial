# Fase 6 — Interface de jogo

Implemente páginas Next.js de jogar, fila e partida. Use design system. Crie tabuleiro responsivo, drag/click, destaques, promoção, clocks, jogadores, lista de lances, ofertas de empate, resign e reconexão. Gere cliente a partir de OpenAPI e use socket tipado.

Teste em desktop e mobile.
